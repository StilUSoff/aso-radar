# ASO Radar

Топ поисковых запросов App Store с разбивкой по гео и позиции приложений по этим запросам.

Два режима:

- **Рынок** — без привязки к приложениям. Сервис перебирает подсказки поиска App Store (автодополнение) по буквам и сочетаниям букв для 50 рынков и строит по каждому рынку рейтинг самых популярных запросов с динамикой между сканами.
- **Приложения** — любое приложение (своё или конкурента) и набор запросов: на каком месте оно в поиске App Store по каждому запросу в каждом рынке. Как в дашборде из поста: плитки с медианной позицией по рынку, секции с метаданными и таблицей позиций.

### Рынок

- **Market snapshot** — плитка на каждый рынок: самый популярный запрос, сколько запросов найдено, сколько новых в топ‑100.
- **Секция рынка** — топ‑500 запросов: позиция, Δ к прошлому скану, тренд, относительная популярность, префикс, на котором запрос всплыл. Клик по запросу показывает топ‑5 приложений App Store по нему.
- **Поиск по гео** — в каких странах встречается запрос и на каком месте.
- **Copy /strategy prompt** — промпт для LLM: кластеры, тренды, ниши, метаданные под рынок.
- Кнопка «+» у запроса добавляет его в отслеживание позиций выбранного приложения.

### Приложения

- **Locale snapshot** — плитка на рынок: медианная позиция приложения и «ranked X/Y» (сколько ключей в топ‑200).
- **Секция рынка** — метаданные (Title / Subtitle / Keywords со счётчиками 30/30/100) и таблица Keyword · Position · Δ · Trend · Last; клик по ключу — топ‑3 выдачи.
- Title подтягивается из выдачи App Store автоматически. Subtitle и Keywords видны только владельцу приложения — их можно вписать вручную.
- Позиции — топ‑200 iTunes Search API, ~3 сек на ключ (лимит Apple ~20 запросов в минуту).

Обе части обновляются автоматически раз в сутки, история 180 дней, экспорт в CSV, доступ по паролю, HTTPS.

Идея интерфейса — ASO‑дашборд из [поста @golyakovph](https://www.threads.com/@golyakovph/post/DXV-QeClIrc).

## Как считается рейтинг рынка

Рынок — это витрина App Store плюс алфавит, на котором набирают запрос. Подсказки зависят только от витрины и введённого текста, поэтому India (Tamil) — это индийская витрина, опрошенная тамильскими буквами. Рынки с одинаковой витриной и алфавитом сканируются один раз: Catalonia = Spain, India (Hindi) = India (Marathi), обе на деванагари. Список рынков и алфавитов — в [app/markets.py](app/markets.py).

**Сбор.**

1. Для каждой буквы алфавита запрашиваются подсказки: Apple отдаёт до 10 самых популярных запросов, подходящих под префикс, в порядке популярности.
2. Уровень глубже: для латиницы и кириллицы — все пары букв (`aa`…`zz`), для остальных алфавитов — только продолжения, встретившиеся в подсказках.
3. **Слова‑мосты.** App Store сопоставляет префикс с началом *любого* слова запроса: на «music» он подсказывает и «music player», и «youtube music». Поэтому дополнительно опрашиваются 150 самых частых «внутренних» слов найденных запросов (vpn, music, editor, maps…) — их списки смешивают запросы с разными первыми буквами.

**Ранжирование.** Каждый список подсказок — это порядок, заданный самим Apple: «первый популярнее второго, второй популярнее третьего, и все десять популярнее остальных подходящих запросов». Все списки рынка сводятся в одну модель ранжирования Plackett–Luce ([app/ranking.py](app/ranking.py)), которая подбирает каждому запросу «силу», согласованную со всеми списками одновременно. Слова‑мосты связывают буквы между собой, поэтому сравнение «chatgpt» с «discord» опирается на реальные порядки Apple, а не на эвристику.

Популярность нормирована: лидер рынка = 100, запрос с 10 встречается в поиске примерно в 10 раз реже. Это **относительная** оценка: абсолютных объёмов Apple не публикует (балл 5–100 есть только в Apple Ads). Индийские языковые рынки и Бангладеш дают мало запросов — там почти всё набирают латиницей.

Полный скан всех рынков — около 35 000 запросов к Apple и ~4 часа.

## Локальный запуск

```bash
cp .env.example .env          # для локальной работы можно оставить DASHBOARD_PASSWORD пустым
docker compose up -d --build
open http://localhost:8000
```

Без Docker (Python 3.10+):

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
DB_PATH=data/aso.db SCAN_INTERVAL_HOURS=0 .venv/bin/uvicorn app.main:app --reload
```

## Развёртывание на сервере (Ubuntu)

Репозиторий приватный, поэтому серверу нужен deploy key:

```bash
# на сервере
ssh-keygen -t ed25519 -f ~/.ssh/aso_radar_deploy -N ""
cat ~/.ssh/aso_radar_deploy.pub    # добавить в GitHub: Settings → Deploy keys (read-only)
cat >> ~/.ssh/config <<'EOF'
Host github-aso-radar
  HostName github.com
  User git
  IdentityFile ~/.ssh/aso_radar_deploy
EOF
git clone git@github-aso-radar:<user>/aso-radar.git ~/aso-radar
cd ~/aso-radar
sudo ./deploy/install.sh      # Docker, .env со случайным паролем, права на data/
./deploy/update.sh            # сборка и запуск
```

Доступ к дашборду:

- **С доменом:** A‑запись домена → сервер, `DOMAIN=...` в `.env`, порты 80/443 открыты, `./deploy/update.sh` поднимет Caddy с HTTPS.
- **Если 443 занят** (например, VPN): `HTTPS_PORT=8443` — дашборд будет на `https://домен:8443`; порт 80 по‑прежнему нужен для выпуска сертификата.
- **Без домена:** сервис слушает только `127.0.0.1:8000` — через SSH‑туннель `ssh -L 8000:localhost:8000 user@server`.

Обновление после `git push`: `cd ~/aso-radar && ./deploy/update.sh`. Данные — в `data/aso.db` (SQLite), для бэкапа достаточно копировать этот файл.

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DASHBOARD_USER` / `DASHBOARD_PASSWORD` | `admin` / — | Логин в дашборд. Пустой пароль отключает авторизацию |
| `SCAN_INTERVAL_HOURS` | `24` | Период автоскана всех рынков, `0` — только вручную |
| `APP_CHECK_INTERVAL_HOURS` | `24` | Период автопроверки позиций приложений, `0` — только вручную |
| `BRIDGE_WORDS` | `150` | Сколько слов‑мостов опрашивать на рынок |
| `TOP_N` | `500` | Сколько запросов хранить на рынок за скан |
| `RETENTION_DAYS` | `180` | Сколько дней хранить историю сканов |
| `HINTS_REQUEST_DELAY` | `0.35` | Пауза между запросами подсказок, сек |
| `SEARCH_REQUEST_DELAY` | `3.2` | Пауза между запросами поиска приложений, сек (лимит Apple ~20/мин) |
| `DOMAIN` | — | Домен для HTTPS через Caddy |
| `HTTPS_PORT` | `443` | Внешний HTTPS‑порт Caddy |
| `APP_PORT` | `8000` | Локальный порт сервиса |
